# LLM Document Frontend

Frontend for the LLM Document RAG application. Built with React, Vite, and Tailwind CSS.

## Features
- Interactive chat interface with AI.
- Document management (Knowledge Base).
- PDF Viewer integration.
- Multi-language support (i18next).
- Comprehensive unit tests with Vitest.

## Tech Stack
- **React** + **Vite**
- **Tailwind CSS**
- **TanStack Query** (React Query)
- **Lucide React** (Icons)
- **i18next** (Internalization)
- **Vitest** + **React Testing Library** (Unit Testing)

## Getting Started
### Prerequisites
- pnpm

### Installation
```bash
pnpm install
```

### Development
```bash
pnpm dev
```

### Testing
```bash
pnpm test
pnpm test:cov # for coverage report
```
